# Compatability
BestestTool requires Paper (or a Paper fork such as Leaves/Purpur) 1.20.6 or newer, and is also
compatible with Folia. It does not support Spigot/CraftBukkit or Bukkit-only server jars. The
1.20.6 floor (raised from 1.20.5) is required by Paper's Brigadier command API
(`io.papermc.paper.command.brigadier`), which the plugin's commands are built on.
